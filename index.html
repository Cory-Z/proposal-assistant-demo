How to use this site

The proposal workflow from RFQ to reviewed draft: SME intake → Comm Ops intake → Cowork with the drafting skill. Use the "Go to" buttons to jump straight to a step or tool.

About this demo

This is a portfolio version of an internal proposal-drafting assistant. The company, clients, people and prices are fictional, and the proposal database holds sample entries only. In the original, the site hands structured intake answers to AI skills that search a proposal index and draft Word and PowerPoint proposals. Here, the prompt builders still run so you can see what they produce, but there is no index folder or AI skill behind them.

Try this: open SME intake, fill in a few answers, copy the result, then paste it into Comm Ops intake.

Other tools on this site

Proposal database

Record a proposal outcome

Wins, losses and no-responses are what let the team see which proposals work and where price or timing loses work. A proposal with a signed copy in the index already counts as won; everything else is unknown until someone records it here. This form prepares a request for the person who maintains the index. Nothing is sent from this page.

Add or correct a proposal in the database

The proposal database is built from a shared Proposals folder, and a weekly scan adds new files automatically. Use this form to get a file added before the next scan, or to fix the tags on an existing entry. It prepares a request for the person who maintains the index; nothing is changed until it is run.

De-identify an RFQ

Everything on this page runs in your browser only - nothing is sent anywhere, not even to Claude. Paste an RFQ below to scan it for likely client names, organization names, model/part numbers, and sentences that may reference proprietary or confidential information. This is a rough first-pass scan meant to speed up your own review - it will over-flag common phrases, so use your judgment on what actually needs to change. As a rule, the two things that must come out before this text goes to Claude are client names and trade secrets.

Tip: If you're copying text from a PDF, use the Print button to open the print preview, then copy the text from there instead of the default PDF view. Text copied from print preview keeps its original order and reads much more cleanly than text copied straight out of a normal PDF viewer.
